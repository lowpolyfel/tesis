# resultados

Salidas de cada corrida, para trazabilidad. Cada corrida debe registrar la fecha,
los modelos, las versiones de prompt, el umbral y el máximo de rondas usados.

Se versionan en git los reportes que se citan en la tesis (por ejemplo
`aceptacion/`, que escribe `scripts/casos_aceptacion.py`). El estado de trabajo
del respaldo JSON del repositorio (`trazas/`, `lel.json`, `proyectos/`,
`documentos/`, `formalizados/`, `validaciones/`, `comparaciones/`,
`evaluaciones/`) no se versiona: está en `.gitignore`.
