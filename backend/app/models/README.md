# models

Esquemas Pydantic compartidos por API, agentes y persistencia:

- `Requisito`: texto original y metadatos.
- `Extraccion`: vocabulario del dominio identificado.
- `Interpretacion`: lectura candidata de un término.
- `Debate`: rondas, argumentos y veredicto.
- `Artefacto`: LEL, metas estratégicas o Big Picture generado.
